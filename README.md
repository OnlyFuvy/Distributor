# Distributor

Музыкальное веб-приложение с сервером на Go и браузерным плеером. В разделе **Анализ уровня сигнала** можно исследовать динамику записи на TypeScript.

## Попробовать анализатор

[Скачать автономную HTML-версию](https://github.com/OnlyFuvy/Distributor/raw/refs/heads/main/frontend/levels/index.html) и открыть в браузере. Сразу виден демосигнал с тихим, громким и бесшумным участками. Можно загрузить свой аудиофайл, поменять шаг, выбрать интервал ползунком и выгрузить результаты в CSV. При запуске сервера Distributor анализатор доступен с главной страницы по ссылке «Анализ уровня сигнала».

### Как устроены измерения

Web Audio API декодирует запись в PCM. Для каждого временного окна модуль находит максимальный модуль отсчёта и считает RMS по отсчётам всех каналов. Противофазные каналы сохраняют энергию. Значения переводятся в dBFS относительно амплитуды 1. Для нуля в таблице и CSV выводится −∞. На графике используется диапазон от −60 до 0 dBFS. Это измерения уровня цифрового сигнала, не оценка воспринимаемой громкости в LUFS. Расчёт занимает O(N × C) для N отсчётов в каждом из C каналов.

### Разработка

Node.js 24+, из каталога frontend/levels:

```sh
npm ci
npm test
npm run build
```

Сборка выполняет строгую проверку TypeScript и встраивает код в один index.html. Для открытия готовой страницы сервер и установка пакетов не требуются.
